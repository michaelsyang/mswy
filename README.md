# mswy

Personal health observations dashboard — a React + Vite + TypeScript SPA
deployed on Cloudflare Pages.

🌐 **Live site**: [mswy.xyz](https://mswy.xyz)

## Features

- Daily health metrics: readiness score, sleep, steps, HRV, RHR, SpO2
- Interactive trend charts (7D / 14D / 30D) with dual-axis HRV + RHR view
- Sleep timeline chart with bedtime → wake mapping and stage breakdown
- Cardio calendar with workout type tracking
- Automated observations & anomaly detection with baseline comparisons

## Tech Stack

- React 19 + TypeScript (strict mode)
- Vite 6 (build tooling)
- Tanstack Query (data fetching) + React Router 7
- Cloudflare Pages (hosting + CDN)
- Hand-rolled SVG charts (no charting library)

## Quick Start

```bash
git clone https://github.com/michaelsyang/mswy.git
cd mswy
npm install
npm run dev
```

Open http://localhost:5173

## Build

```bash
npm run build    # outputs to dist/
npm run preview  # preview the production build
```

## Deployment

Deployed to Cloudflare Pages via wrangler:

```bash
npx wrangler pages deploy dist --project-name=mswy --branch=main --commit-dirty=true
```

Production branch: `main`. Live at:

- https://mswy.xyz
- https://mswy-xyz.pages.dev

## Project Structure

```
src/
  components/health/   Dashboard components (charts, calendar, observations)
  components/ui/       Shared UI elements (error/loading states)
  hooks/               Data fetching hooks
  lib/                 Types, health utilities, SVG utilities
  pages/               Route pages (dashboard, home, 404)
  styles/              Global CSS
public/
  _headers             Cache control (no-store HTML, immutable assets)
  _redirects           SPA fallback routing
  data.json            Health data (generated by external pipeline)
dist/                  Build output (gitignored)
```

## Data

Health data (`public/data.json`) is generated by an external sync pipeline.
Do not edit it manually — it is overwritten on each sync.
